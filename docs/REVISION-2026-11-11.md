# Revisión y actualización de B-Software

Sitio: https://bsoftware.pages.dev/

Proyecto Cloudflare Pages: `bsoftware`, rama de producción `main`.

## Problemas encontrados

- La publicación de julio contenía Contacto, Privacidad, Términos, Cookies,
  traducciones y un pie de página que faltaban en el repositorio. Compilar
  directamente desde `main` hubiera eliminado esas páginas.
- Los casos de RRHH y Tiago Market no reflejaban su documentación pública actual.
- El enlace público del repositorio de Suplencias devolvía 404.
- El selector de idioma dependía de que localStorage estuviera disponible y
  podía conservar texto del idioma anterior después de cambiar una pestaña.
- Había contrastes insuficientes en las páginas de proyectos, y el diagrama
  dependía del arrastre con puntero para modificar su disposición.
- Las dependencias instaladas inicialmente tenían 13 entradas vulnerables en
  `npm audit --omit=dev`, incluidas dependencias de Astro 5. El sitio publicado
  es estático; ese resultado describe herramientas y dependencias, sin demostrar
  explotación del sitio.

## Cambios

- Recuperación de las páginas legales y sus textos originales de producción.
  Se conservaron las fechas y el contenido en español; se completó el inglés.
- Portada más compacta, vista real de demostración de RRHH en WebP y accesos
  a la demo web de Tiago Market, al código y a la documentación.
- Estado de RRHH con siete módulos y separación explícita entre la distribución
  operativa 1.0.6.7 y el desarrollo posterior de Ficha y Licencias.
- Contacto compartido entre portada y `/contacto/`, validación de espacios,
  email o teléfono, longitudes máximas y enlace para reabrir el borrador si el
  navegador bloquea la ventana. No se envían mensajes automáticamente.
- Navegación móvil que se cierra al elegir un enlace, al presionar Escape o al
  pulsar fuera del menú. Navegación del diagrama con flechas y Mayús.
- Preferencia ES/EN tolerante al bloqueo del almacenamiento; traducciones en
  un archivo compartido con caché, sin repetir el diccionario en cada HTML.
- Página 404, sitemap actualizado, cabeceras de seguridad y configuración
  explícita del proyecto y cuenta de Cloudflare.
- Astro 7.4.10, Tailwind 4.3.5 y herramientas compatibles actualizadas. Node
  mínimo 22.23.4; `.nvmrc` recomienda Node 24.

## Verificación reproducible

```powershell
npm ci
npx playwright install chromium
npm run check
npm run build
npm test
npm audit
```

Las pruebas recorren las nueve páginas públicas en escritorio y móvil y verifican
recursos, errores de JavaScript, metadatos, accesibilidad con axe, enlaces y
fragmentos internos, idioma, navegación, teclado, formulario, localStorage
bloqueado, uso sin JavaScript y respuesta 404. No contactan a personas ni envían
mensajes de WhatsApp.

También se comprobaron los enlaces externos a las demos y repositorios públicos,
la portada a 320 px y la igualdad del contenido legal con la publicación anterior.
La captura de RRHH procede de su galería pública y se identifica como demostración
con datos ficticios; no se publican registros operativos.

Resultado: 32 pruebas aprobadas tanto en local como en la vista previa de
Cloudflare, sin fallos ni pruebas inestables. `astro check`: cero errores,
advertencias e indicaciones. `npm audit`: cero vulnerabilidades.
